# Provenance

This repository was extracted from the committed `coupled` branch of
[`Numi2/numi-lab`](https://github.com/Numi2/numi-lab) at revision
`f6398a328310131ee0272e5df5fe934b32a4c639` (2026-08-15).

The extraction intentionally excludes Numi Lab training, MLX integration,
rendering, application UI, command overlays, unrelated robot models, and run
telemetry. Shared ABI headers are retained where the solver's packed Metal
layouts require them.
